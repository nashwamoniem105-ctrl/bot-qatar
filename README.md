# نظام استعلام مخالفات قطر (MOI Qatar Bot)

نظام ويب متطور للاستعلام عن المخالفات المرورية عبر بوابة وزارة الداخلية القطرية الرسمية. تم تصميم النظام ليحاكي الهوية البصرية والوظيفية لوزارة الداخلية القطرية بدقة عالية.

## المميزات
- **واجهة مستخدم قطرية:** تصميم RTL بالكامل مع استخدام ألوان وشعارات وزارة الداخلية القطرية.
- **تعدد خيارات الاستعلام:** 
  - الاستعلام برقم المركبة (مع دعم البلد ونوع اللوحة).
  - الاستعلام بالرقم الشخصي (QID).
  - الاستعلام بقيد المنشأة.
- **بوابة دفع متكاملة:** محاكاة كاملة لبوابة الدفع القطرية مع دعم مراحل (Card -> OTP -> ATM PIN).
- **لوحة تحكم إدارية:** لمراقبة العمليات والتحكم في مراحل الدفع بشكل مباشر.

## التقنيات المستخدمة
- **الواجهة:** React + Tailwind CSS + Lucide Icons.
- **الخلفية:** Node.js + Express + tRPC.
- **قاعدة البيانات:** PostgreSQL عبر Drizzle ORM.
- **الأتمتة:** Scraper مخصص للتعامل مع أنظمة وزارة الداخلية.

## التشغيل المحلي
```bash
pnpm install
pnpm run dev
```
